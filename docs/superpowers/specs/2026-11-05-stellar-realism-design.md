# 正式星图恒星外观

用户已确认 `.superpowers/stellar-preview` 第二版的动态材质与比例，并明确要求接入正式页面、黑洞保持原样。

- 恒星沿用程序生成的光球颗粒、缓慢演化、边缘渐暗、细碎日冕与日珥，以及九颗恒星的颜色差异。
- 沿用预览的画面比例：黑洞阴影直径约为恒星的 4.8–10.5 倍，随同一镜头线性缩放。仅调整美术尺寸，不改恒星碰撞半径、质量、轨道、时钟或记录。
- 保留现有黑洞的绘制函数、颜色、吸积盘和缩放系数。
- 正式页面保留卫星、历史回放、选择发射点等操作；增加恒星特写选择，跟随所选恒星，允许拉近看程序材质细节。
- 将最大视野缩放从 200% 扩展到 6400%，保留现有最小可观测区域与鼠标锚点缩放。
- GPU 不可用或上下文丢失时使用简化 Canvas 光球，不影响轨道控制；上下文恢复后重新使用程序材质。

## 实现选择

采用一个共享的离屏 WebGL 渲染器，批量绘制可见恒星并合成到原星图 Canvas，保持黑洞、恒星、轨迹、卫星和辅助标记的绘制顺序。相比九个独立 WebGL 上下文减少资源；相比额外覆盖整个页面的 DOM 图层，保留现有图层顺序与鼠标操作。独立照片和外部 3D 模型不符合用户确认的动态程序外观。

## 验证

覆盖比例随缩放不变、极远景不产生固定大小亮点、特写不限制星体尺寸、GPU 回退与恢复、恒星特写和卫星跟踪互斥、暂停/补算/回放时钟不变。真实浏览器确认着色器、近景和全景；运行完整测试。
