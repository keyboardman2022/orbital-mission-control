# ORBITAL 安卓离线版实现计划

目标是在独立目录交付一个可侧载的 APK。飞行模拟、存档和静态网页随应用一起运行，飞行模式下仍可使用。

1. 用现有 Node 24 模拟服务和 SQLite 作为手机端引擎。应用在自己的数据目录启动服务，以随机端口和随机访问令牌隔离本机接口。验证无令牌访问、种子地图发射和重启持久化。
2. Android Activity 在应用私有目录解包游戏资源，嵌入 Node 运行时并用 WebView 打开任务控制台。页面导航限于本机服务，通过 Android 文件选择器保存轨迹、恢复密钥和登舰卡。
3. 用固定版本的 SDK 和原生运行时构建并签名 APK。校验签名、支持的架构与安装包资源。如有可用设备，验证断网启动、保存和重启。

应用使用新建的独立存档。模拟服务跟随 Android 应用进程的生命周期，退出后可以从最近一次保存的进度继续。
